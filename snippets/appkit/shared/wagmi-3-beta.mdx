<Note>
**Wagmi 3.0 support (beta)**

A beta version of AppKit that supports Wagmi 3.0 is available. To use it:

1. Update all `@reown/*` packages to `2.0.0-wagmi-3.0`.
2. Update `wagmi` to the latest version (for Vue and Nuxt, update `@wagmi/vue`).
3. Add the `@wagmi/connectors` package.

Check the working examples in the [AppKit+Wagmi3 branch](https://github.com/reown-com/appkit-web-examples/tree/rtomas/bump-wagmi-3.7.7) of the AppKit web examples repository, or follow the [step-by-step migration guide](/appkit/react/core/wagmi-3-migration).
</Note>
