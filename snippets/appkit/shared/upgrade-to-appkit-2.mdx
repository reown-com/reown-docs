<Note>
**Upgrade from AppKit 1.x to 2.x**

1. Update all `@reown/*` packages to the latest 2.x version (`@reown/appkit@latest`). All Reown packages must use the same version.
2. If you use the Wagmi adapter, update `wagmi` to the latest version (for Vue and Nuxt, update `@wagmi/vue`) and `viem` to the latest 2.x version.
3. If you use the Wagmi adapter, add the `@wagmi/connectors` package.

Check the [AppKit web examples](https://github.com/reown-com/appkit-web-examples) for working 2.x projects, or follow the [step-by-step migration guide](/appkit/react/core/wagmi-3-migration).
</Note>
