<Warning>
  AppKit support for Wagmi 3.0 is in beta. Test your app thoroughly before shipping to production.
</Warning>

This guide walks through upgrading a React project that uses the Wagmi adapter from AppKit `1.x` with Wagmi `2.x` to the AppKit beta (`2.0.0-wagmi-3.0`) with Wagmi `3.x`.

It uses the [React Wagmi example](https://github.com/reown-com/appkit-web-examples/blob/main/react/react-wagmi/package.json) as the starting point and the [upgraded React Wagmi example](https://github.com/reown-com/appkit-web-examples/tree/rtomas/bump-wagmi-3.7.7/react/react-wagmi) as the end result. Only `package.json` changes. The application code stays the same.

## Before and after

```diff package.json
  "dependencies": {
-   "@reown/appkit": "1.8.21",
-   "@reown/appkit-adapter-wagmi": "1.8.21",
+   "@reown/appkit": "2.0.0-wagmi-3.0",
+   "@reown/appkit-adapter-wagmi": "2.0.0-wagmi-3.0",
    "@tanstack/react-query": "5.90.3",
-   "@wagmi/connectors": "6.2.0",
+   "@wagmi/connectors": "8.2.0",
    "react": "19.2.1",
    "react-dom": "19.2.1",
-   "viem": "2.47.0",
-   "wagmi": "2.19.5"
+   "viem": "2.56.8",
+   "wagmi": "3.7.7"
  }
```

## Migration steps

<Steps>
<Step title="Update the Reown packages">

Set every `@reown/*` package in your project to `2.0.0-wagmi-3.0`. All Reown packages must use the same version, including any additional adapters (for example `@reown/appkit-adapter-solana` or `@reown/appkit-adapter-bitcoin`).

```json package.json
"@reown/appkit": "2.0.0-wagmi-3.0",
"@reown/appkit-adapter-wagmi": "2.0.0-wagmi-3.0"
```

</Step>
<Step title="Update Wagmi and viem to the latest version">

Update `wagmi` to the latest `3.x` release and `viem` to the latest `2.x` release.

```json package.json
"viem": "2.56.8",
"wagmi": "3.7.7"
```

</Step>
<Step title="Add the @wagmi/connectors package">

Wagmi 3.0 requires `@wagmi/connectors` as a direct dependency. Add it, or update it to the latest version if your project already includes it.

```json package.json
"@wagmi/connectors": "8.2.0"
```

</Step>
<Step title="Reinstall dependencies">

Remove `node_modules` and your lockfile, then install the updated packages:

<CodeGroup>

```bash npm
npm install @reown/appkit@2.0.0-wagmi-3.0 @reown/appkit-adapter-wagmi@2.0.0-wagmi-3.0 wagmi@latest viem@latest @wagmi/connectors@latest
```

```bash Yarn
yarn add @reown/appkit@2.0.0-wagmi-3.0 @reown/appkit-adapter-wagmi@2.0.0-wagmi-3.0 wagmi@latest viem@latest @wagmi/connectors@latest
```

```bash Bun
bun add @reown/appkit@2.0.0-wagmi-3.0 @reown/appkit-adapter-wagmi@2.0.0-wagmi-3.0 wagmi@latest viem@latest @wagmi/connectors@latest
```

```bash pnpm
pnpm add @reown/appkit@2.0.0-wagmi-3.0 @reown/appkit-adapter-wagmi@2.0.0-wagmi-3.0 wagmi@latest viem@latest @wagmi/connectors@latest
```

</CodeGroup>

</Step>
<Step title="Run your app">

Start your app and confirm that the AppKit modal opens and wallets connect as before. Your `WagmiAdapter` and `createAppKit` configuration stays the same.

If your app calls Wagmi hooks or actions directly, check the [Wagmi 3.x migration guide](https://wagmi.sh/react/guides/migrate-from-v2-to-v3) for breaking changes in the Wagmi API.

</Step>
</Steps>
